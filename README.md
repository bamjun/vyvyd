# vyvyd 🎬 (MP4 to GIF, Image Editor & GIF/Image Merge)

영상·이미지를 브라우저에서 변환·편집하고, 포스터 메이커의 프로젝트와 파일을 이 컴퓨터의 로컬 서비스에 보관하는 미디어 작업 앱입니다.

배포 주소: [https://vyvyd.pages.dev](https://vyvyd.pages.dev)

---

## ✨ 핵심 기능 (Key Features)

1. **고화질 MP4 to GIF 변환 (FFmpeg WASM)**
   - 브라우저 클라이언트 내의 WebAssembly 가상 환경에서 FFmpeg 엔진을 네이티브로 실행합니다.
   - **2단계 팔레트 추출 기법(Pass-1 Palette Gen)**을 도입하여 원본 비디오의 모든 색상 스펙트럼을 정밀하게 추출하고 색 왜곡 및 번짐을 방지합니다.
   - **디더링 옵션 지원**: Bayer, Floyd-Steinberg 등 고성능 디더링 알고리즘 제공.
   - **기타 조정 옵션**: 재생 구간 정밀 트리밍(Trim), 해상도 비율 조절(Scale), 프레임 레이트(FPS) 설정.
   - 여러 MP4 파일을 한 번에 선택해 일괄 변환할 수 있으며, 출력 가로·세로 크기를 숫자로 직접 입력할 수 있습니다.
   - 가로·세로 영상을 섞어도 각 영상의 원본 비율을 기본값으로 유지합니다. 목록에서 영상을 선택해 자르기·변환 구간·출력 크기를 개별 편집할 수 있습니다.
   - **비율 잠금**은 자르기 영역에 맞춰 출력 가로·세로를 함께 조정합니다. **전체 맞춤**은 전체 영역을 보존하고 남는 공간을 투명하게, **영역 채우기**는 비율을 유지하며 중앙 기준으로 넘치는 부분을 자릅니다.
   - 출력 구도를 현재 프레임으로 미리 확인할 수 있습니다. **모든 영상에 같은 출력 크기 적용**은 출력 크기와 맞춤 방식만 복사하고 각 영상의 자르기 영역과 변환 구간을 유지합니다.

2. **애니메이션 손실 없는 GIF 크롭**
   - FFmpeg를 통해 업로드된 GIF 파일의 각 애니메이션 프레임, 딜레이 시간 및 알파 채널 투명도를 보존하면서 특정 크기 영역을 무손실 크롭합니다.

3. **고급 UI 크롭 박스 (Crop Overlay)**
   - 마우스 드래그를 통해 영역을 마음대로 지정하고 이동할 수 있습니다.
   - 상/하/좌/우 선 경계선 및 4개 모서리(Corner) 드래그 리사이즈 핸들을 지원합니다.
   - 이미지·GIF와 영상에서 **1:1·4:5·9:16**을 선택하면 원본 안에 들어가는 최대 크롭 영역을 중앙에 배치합니다. 이후 숫자 입력과 드래그로 크기를 바꿔도 선택한 비율을 유지합니다.
   - **중앙으로 배치**는 현재 크기를 유지한 채 영역을 가운데로 옮깁니다. **자유**는 비율 잠금을 해제하고, **전체 영역**은 원본 전체로 되돌립니다. 영상별 크롭 프리셋은 각각 유지합니다.
   - **Pointer Capture API**를 적용하여 마우스가 크롭 영역 밖에서 떼어지더라도 드래그 멈춤 상태가 올바르게 반응합니다.

4. **로컬 처리와 저장**
   - 영상 변환과 이미지 편집은 브라우저에서 처리합니다. 포스터 메이커의 소스와 이미지 파일은 사용자의 컴퓨터에 실행한 루프백 서비스에 저장합니다. Discord 전송은 사용자가 선택할 때만 실행합니다.

5. **이미지 9:16 변환**
   - 원본을 확대하거나 자르지 않고 9:16 캔버스에 **상단·중앙·하단**으로 배치합니다. 원본이 캔버스보다 길면 원본 높이를 유지합니다.
   - 기본값은 투명 영역이며, 흰색 영역을 선택해 PNG로 내려받을 수도 있습니다.

6. **이미지 일괄 축소**
   - JPG, PNG, WebP 파일을 여러 개 한 번에 선택해 브라우저에서 일괄 처리합니다.
   - 원본 비율과 전체 이미지를 유지하며 자르기 없이 가로·세로 크기만 줄입니다.
   - 원본 대비 비율 또는 최대 가로·세로 크기를 지정할 수 있고, 원본보다 작은 이미지는 확대하지 않습니다.
   - 원본 형식 유지 또는 JPG, PNG, WebP 출력과 화질 조절을 지원합니다.

7. **이미지·GIF 가로/세로 합치기**
   - Image Editor의 **합치기**에서 이미지 또는 GIF 모드를 선택하고 여러 파일을 추가합니다.
   - 이미지 모드는 JPG, PNG, WebP만, GIF 모드는 GIF만 받으며 두 종류를 섞어 올릴 수 없습니다.
   - 파일 순서를 바꾸거나 개별 삭제할 수 있고, 가로 또는 세로 배치와 결과 크기를 미리 확인합니다.
   - **원본 크기** 또는 가로 합치기의 **같은 높이로 맞춤**, 세로 합치기의 **같은 너비로 맞춤**을 선택합니다. 크기 맞춤은 가장 작은 높이·너비에 맞춰 원본 비율을 유지하며 축소합니다.
   - 가로 배치는 **상단·중앙·하단**, 세로 배치는 **왼쪽·중앙·오른쪽** 정렬을 지원합니다. 크기 차이로 생기는 여백은 투명하게 채우며 미리보기와 결과에 같은 설정을 적용합니다.
   - 이미지는 PNG로, GIF는 애니메이션을 유지한 GIF로 저장합니다. 길이가 다른 GIF는 가장 긴 파일에 맞추고 짧은 파일은 마지막 프레임을 유지합니다.
   - 모든 합치기는 브라우저에서 처리하며, 결과를 다운로드하거나 선택적으로 Discord에 보낼 수 있습니다.

## 포스터 메이커

빈 프로젝트를 만들고 이름·크기·FPS·길이·배경을 설정하며, 이미지 파일을 추가하고 저장본을 다시 열 수 있습니다. 파일 추가는 즉시 저장하고 설정 변경은 **저장** 버튼으로 반영합니다.

별도 터미널에서 로컬 서비스와 앱을 각각 실행하세요.

```bash
npm run studio:server
```

```bash
npm run dev
```

[포스터 메이커](http://127.0.0.1:5173/?studio=1)를 열면 프로젝트는 `.local/studio/projects/`에 보관됩니다. 현재 Codex에서 프로젝트를 읽고 Remotion 소스를 작성·수정하려면 최초 1회 `npm run studio:setup`으로 이 프로젝트의 MCP 설정을 등록하세요. 도구가 목록에 나타나지 않으면 MCP 연결을 갱신하거나 세션을 다시 열고 **같은 대화**를 이어서 진행합니다. 현재 컴퓨터에서는 실제 도구 호출까지 확인했습니다.

프로젝트를 열고 **현재 Codex에 작업 요청**에 원하는 작업을 적은 뒤 **프로젝트 요청 문구 복사**를 눌러 현재 대화에 붙여넣으세요. Codex가 소스를 검증하고 반영하면 브라우저 미리보기가 갱신됩니다. 이 버튼은 요청 문구를 복사하며 대화를 자동 실행하지 않습니다.

2026-10-03에 현재 Codex 대화의 실제 MCP 도구로 소스를 수정해 프로젝트 버전 5→6 반영, 35프레임 미리보기, 브라우저의 버전 6·MCP 최근 연결 표시와 46프레임 복원을 확인했습니다. [1단계 기록](docs/remotion-studio-stage-1.md)과 [2단계 기록](docs/remotion-studio-stage-2.md)에 실행·검증 내용을 정리했습니다. 2단계는 로컬 환경에서 완료되어 사용자 검토를 기다리고 있으며, 레이어 직접 편집은 3단계에서 진행합니다. 배포된 HTTPS 화면과 로컬 서비스의 연결은 아직 성공 확인 전입니다.

## 작업 유지와 취소

- 상단 탭을 옮겨도 선택한 파일, 편집 설정, 완료된 결과와 진행 중인 작업을 유지합니다. 페이지를 새로고침하거나 닫으면 초기화됩니다.
- 영상 변환과 이미지 편집의 처리 화면에서 **작업 취소**를 누를 수 있습니다. 일괄 처리에서 이미 표시된 완료 결과는 다운로드할 수 있습니다.
- 영상·GIF 변환은 공통 대기열에서 순서대로 실행합니다. 대기 작업을 취소해도 다른 도구에서 실행 중인 작업에는 영향을 주지 않습니다.
- 영상 탭을 떠나면 미리보기 재생을 멈추고, 변환은 계속 진행합니다.
- 영상 일괄 변환은 한 파일이 실패해도 나머지를 계속 처리합니다. 파일별 상태와 실패 단계를 표시하며, 설정을 수정해 **실패한 파일만 전체 또는 개별 재시도**할 수 있습니다. 재시도할 때 완료된 GIF는 유지합니다.
- 취소로 처리하지 못한 파일은 실패와 구분해 **남은 파일 이어서 변환**으로 실행할 수 있습니다. **전체 다시 변환**은 기존 결과를 초기화하고 모든 파일에 현재 설정을 적용합니다.

회귀 검증은 `npm test`, 정적 검사와 빌드는 `npm run lint`, `npm run build`로 실행합니다.

## 목표 용량 자동 최적화

- **MP4 to GIF**와 **크기 줄이기**에서 자동 최적화를 켜고 파일당 최대 용량을 KB/MB로 입력합니다. 입력 범위는 1 KB~100 MB이며 1 KB는 1,024바이트입니다.
- 현재 설정으로 먼저 처리한 뒤 실제 파일 용량을 측정하며 최대 12회 조절합니다. JPG/WebP는 화질을, GIF는 색상 수를 줄이고 영상 GIF는 FPS도 줄인 다음 필요하면 출력 크기를 줄입니다. PNG는 크기를 조절합니다.
- 선택한 저장 형식, 비율, 자르기 영역, 변환 구간은 유지합니다. 이미지 GIF는 원본 재생 타이밍을 유지하며 수동으로 입력한 크기·화질·FPS 설정을 덮어쓰지 않습니다.
- 결과마다 실제 출력 크기와 적용 설정, 시도 횟수, 목표 달성 여부를 표시합니다. 목표가 너무 작거나 탐색 한계에 도달하면 측정한 결과 중 가장 작은 파일을 제공하며 **목표 용량 초과**라고 명시합니다.
- 작업 취소, 탭 이동 시 작업 유지, 영상의 실패 파일만 재시도, 결과 이어 편집도 사용할 수 있습니다. 중간 시도의 결과는 저장하거나 전송하지 않습니다.

## 결과 이어 편집

- 영상 변환·자유 자르기·9:16 여백·크기 줄이기·분할·합치기 결과에서 **크기 줄이기**, **분할하기**, **합치기에 추가**로 이동할 수 있습니다. 여러 결과는 한 번에 전달할 수도 있습니다.
- 결과 파일을 브라우저 안에서 복사해 대상 도구에 추가합니다. 원래 결과를 초기화해도 전달한 파일은 유지되며, 대상 도구의 기존 파일·설정·완료 결과도 보존합니다.
- GIF 파일은 GIF로 전달됩니다. 크기 줄이기에서 **원본 형식 유지**를 선택하면 애니메이션도 유지됩니다.
- 합치기 목록이 비어 있으면 파일 종류에 따라 이미지/GIF 모드를 선택합니다. 기존 목록과 종류가 다르거나 GIF와 정지 이미지가 섞여 있으면 기존 목록을 유지하고 안내합니다. 대상 도구가 처리·로딩·전송 중이면 완료 후 다시 추가할 수 있습니다.

## 🛠 기술 스택 (Tech Stack)

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Core Processing Engine**: `@ffmpeg/ffmpeg` (v0.12), `@ffmpeg/util`
- **Deployment Platform**: Cloudflare Pages

## 🚀 시작하기 (Getting Started)

### 1. 패키지 설치
```bash
npm install
```

### 2. 로컬 개발 서버 실행
```bash
npm run dev
```
*로컬 서버는 `http://localhost:5173`로 시작합니다.*

> [!IMPORTANT]
> 로컬 브라우저에서 FFmpeg WASM 구동(SharedArrayBuffer 기능)을 위해, Vite 개발 서버 실행 시 자동으로 Cross-Origin Isolation 헤더(`COOP`/`COEP`)가 주입되도록 `vite.config.ts` 파일이 이미 세팅되어 있습니다.

### 3. 프로덕션 빌드
```bash
npm run build
```

### 4. 클라우드플레어 페이지 배포
```bash
npm run deploy
```
*`npm run build`를 실행한 후 Wrangler CLI를 활용하여 빌드된 `dist` 폴더를 Cloudflare Pages의 `vyvyd` 프로젝트로 배포합니다. 환경변수는 사용하지 않으며, 최초 1회만 `npx wrangler login`이 필요합니다.*
