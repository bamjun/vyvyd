# 포스터 메이커 사용 안내

## npm 패키지로 사용하기

저장소 전체를 내려받지 않아도 Node.js 22.14 이상과 Chrome 또는 Edge가 있으면 사용할 수 있습니다.

```sh
npm install -g @bamjun/vyvyd-studio
vyvyd-studio setup
vyvyd-studio start
```

[배포 포스터 메이커](https://vyvyd.pages.dev/?studio=1)를 열고 로컬 네트워크 접근 권한을 허용합니다. Codex의 MCP 연결을 다시 시작한 뒤 현재 대화를 이어갑니다. 서비스 터미널은 사용하는 동안 켜 두세요. 명령 옵션·사용자 데이터 저장 위치·기존 개발 데이터 가져오기는 [패키지 사용 안내](../packages/studio-companion/README.md)에 설명합니다.

이하 `npm run studio:*` 명령과 `.local/studio` 경로는 **개발 저장소에서 실행하는 방식**입니다. npm CLI의 기본 데이터 폴더와 구분하세요.

포스터 메이커에서 프로젝트·이미지·레이어를 관리하고 PNG·GIF·MP4를 출력합니다. 새 디자인이나 애니메이션 코드는 현재 Codex 대화에서 요청합니다. `ad-mage`의 템플릿을 가져올 필요 없이 빈 프로젝트에서 시작할 수 있습니다.

## 설치와 실행

이 저장소의 로컬 검증 환경은 **Windows, Node.js 22.17.0, 설치된 Chrome 또는 Edge**입니다. 루트 `package.json`에는 Node `engines`를 지정하지 않았습니다. 설치된 Vite·ESLint·MCP 패키지의 요구사항을 합치면 Node 18.18 이상인 18.x 또는 Node 20 이상이 필요하며, 모든 해당 버전에서 앱 전체를 검증한 것은 아닙니다.

저장소 폴더에서 패키지를 설치합니다.

```powershell
npm ci
```

서로 다른 터미널 두 개에서 아래 명령을 실행하고 작업 중에는 두 터미널을 유지합니다.

```powershell
npm run studio:server
```

```powershell
npm run dev
```

[로컬 포스터 메이커](http://127.0.0.1:5173/?studio=1)를 엽니다. 기본 로컬 서비스 주소는 `http://127.0.0.1:4180`입니다. 포스터 메이커에 **로컬 서비스 연결됨**이 표시되면 프로젝트를 만들거나 열 수 있습니다. 기존 영상·이미지 도구는 포스터 서비스 없이도 사용할 수 있습니다.

현재 Codex에서 이 프로젝트를 작업하려면 최초 1회 다음 명령으로 프로젝트의 MCP 연결 설정을 등록합니다. 이 명령은 저장소의 `.codex/config.toml`에 `vyvyd-studio`를 추가하고 기존 설정은 보존합니다.

```powershell
npm run studio:setup
```

Codex에서 MCP 연결을 갱신한 뒤 **같은 대화**를 이어갑니다. 브라우저의 로컬 서비스 연결 상태와 MCP 최근 연결·도구 호출 상태는 별개입니다. MCP가 아직 사용되지 않았다는 표시만으로 로컬 저장 서비스가 끊긴 것은 아닙니다.

## 만들기와 편집

1. **새 프로젝트**에서 이름·캔버스 크기·FPS·길이를 정합니다.
2. **이미지 파일 추가**로 PNG·JPG·WebP·GIF를 보관합니다. 이미지당 최대 20 MiB, 프로젝트당 최대 100개입니다. 파일 추가는 바로 저장됩니다.
3. **현재 Codex에 작업 요청**에 원하는 디자인을 쓰고 **프로젝트 요청 문구 복사**를 눌러 현재 대화에 붙여넣습니다. 복사 버튼은 대화를 자동으로 실행하지 않습니다.
4. Codex가 저장한 디자인의 미리보기가 준비되면 **레이어 편집**에서 직접 고칩니다. 새 레이어를 만들거나 코드에서만 표현하는 요소를 변경하려면 Codex에 요청합니다.
5. 직접 편집 후 **저장**을 누릅니다. Codex와 출력 기능은 저장된 프로젝트를 사용합니다.

등록된 레이어를 클릭하고 드래그하거나 위치·크기·회전·문구·색상·불투명도·이미지 값을 조절합니다. 표시되는 편집 항목은 해당 디자인이 지원하는 항목입니다. 캔버스에 초점을 둔 상태에서 방향키로 1px, Shift+방향키로 10px 움직입니다. 숨김·잠금을 사용할 수 있고 **앞으로/뒤로**는 순서 편집을 지원하는 같은 부모의 레이어에 적용됩니다.

**되돌리기/다시 실행**은 현재 편집 이력입니다. 드래그 한 번이 한 단계이며 Ctrl/⌘+Z, Ctrl/⌘+Shift+Z 또는 Ctrl+Y를 사용할 수 있습니다. 글자 입력 칸에서는 해당 입력 칸의 단축키를 사용합니다. 새로고침 뒤에는 Undo/Redo의 전체 이력이 유지되지 않습니다.

## 저장본·초안·이력의 차이

| 항목 | 보관 위치와 사용 |
| --- | --- |
| 저장본 | 로컬 서비스의 디스크. 저장 버전 번호가 있으며 Codex·출력·프로젝트 파일 만들기가 사용합니다. |
| 미저장 초안 | 브라우저의 현재 탭. 탭·프로젝트 이동 시 보관하고 같은 탭의 새로고침 복구를 위해 임시 저장합니다. |
| 저장 버전 이력 | 로컬 서비스의 디스크. 이전 소스·설정·레이어를 복원하면 새 저장 버전이 생깁니다. |

초안은 저장본을 대신하는 백업이 아닙니다. 탭을 닫거나 브라우저 저장 공간을 지우면 잃을 수 있으며 다른 브라우저·사이트 주소로 자동 이동하지 않습니다. 임시 저장 공간이 부족하면 화면에 안내합니다. 중요한 변경은 **저장**하고 프로젝트 파일로 보관하세요.

미저장 입력이 있을 때 Codex가 저장본을 바꾸면 자동으로 덮어쓰지 않고 두 상태를 표시합니다. **최신 저장본 다시 읽기**는 저장본을 사용하며, **내 입력 유지하고 최신 버전 사용**은 지원되는 직접 편집 값을 새 소스에 적용합니다. 화면을 확인한 뒤 저장하세요. 소스 변경·버전 복원 전에 보관한 초안은 **이전 입력 가져오기**로 다시 적용할 수 있습니다.

**저장 버전** 목록에서 버전을 선택하고 **버전 N으로 복원**합니다. 복원 전 소스를 검증하며 추가한 이미지 파일은 계속 보관합니다. 오류가 발생하면 메시지를 확인하고 현재 디자인이나 마지막 정상 미리보기를 이어 사용할 수 있습니다.

## 출력과 이어 편집

**포스터 출력**에서 형식과 크기를 선택합니다. 현재 편집을 출력하려면 먼저 저장하세요. 작업 시작 시 저장 버전·소스·이미지가 고정되어 출력 중 후속 편집이나 저장과 섞이지 않습니다.

| 형식 | 사용 방법 |
| --- | --- |
| PNG | 한 프레임을 선택합니다. **현재 미리보기 프레임 사용**과 **투명 배경 PNG**를 사용할 수 있습니다. |
| GIF | 전체 길이를 출력합니다. 길이를 유지할 수 있는 FPS와 총 재생 횟수 또는 무한 반복을 선택합니다. |
| MP4 | 원본 FPS·전체 길이를 유지합니다. 출력 가로·세로는 짝수여야 합니다. |

출력 크기는 원본 비율을 유지합니다. 크기 오류가 표시되면 원본·50%·25% 등 표시된 프리셋을 사용하세요. PNG 투명 설정은 캔버스 배경을 제거하지만 디자인 코드에 직접 넣은 불투명 도형·이미지·배경은 남습니다. GIF·MP4에는 투명 배경을 제공하지 않습니다. 선택한 배경색은 디자인 코드가 프로젝트 배경 값을 사용하는 부분에 적용됩니다.

출력 이력에서 진행률·실패 메시지를 확인하고 **작업 취소**, **같은 설정 재시도**를 사용할 수 있습니다. 재시도는 원래 작업의 저장 버전과 설정을 사용합니다. 새 편집을 반영하려면 저장 후 새 출력을 시작하세요. 한 번에 하나씩 출력하며 대기·진행 작업은 최대 8개입니다. 영상 길이·픽셀 수 등 출력 한도를 넘으면 안내합니다.

완료 후 **결과 보기**에서 미리보기와 다운로드를 엽니다. PNG·GIF는 **크기 줄이기·분할하기·합치기에 추가**, MP4는 **영상 변환으로 보내기**를 사용할 수 있습니다. 대상 도구의 기존 파일·설정·완료 결과를 유지합니다. 처리 중이거나 파일 종류를 함께 사용할 수 없는 도구는 전달을 거절하고 이유를 안내합니다.

출력 취소와 영상·이미지 변환 취소는 각각의 작업에 적용됩니다. 포스터 서비스가 중단되면 진행 출력은 실패로 표시되며 다시 실행한 뒤 재시도할 수 있습니다. 완료 결과와 출력 이력은 서비스 재시작 후에도 보관합니다.

## 프로젝트 파일로 보관·이동

**프로젝트 파일 만들기** 후 표시된 다운로드 링크로 `.vyvyd.json` 파일을 받습니다. 현재 저장본의 소스·이미지·편집 값을 포함하며 미저장 초안·저장 버전 이력·출력 결과·MCP 요청 기록은 포함하지 않습니다.

**프로젝트 파일 가져오기**는 새 ID·버전 1의 별도 프로젝트를 만듭니다. 기존 프로젝트를 덮어쓰지 않습니다. 가져온 소스는 이후 컴파일하며 오류는 소스 상태에 표시합니다. 이미지 합계 100 MiB, JSON 전체 145 MiB 한도와 파일 손상 여부를 검사합니다. 다른 컴퓨터에서도 로컬 서비스와 필요한 패키지·브라우저를 준비해야 합니다.

## 연결·오류 복구

| 화면이나 증상 | 확인할 내용 |
| --- | --- |
| 로컬 서비스 연결 필요 | `npm run studio:server` 터미널이 살아 있는지 확인하고 **다시 연결**을 누릅니다. 연결이 끊겨도 이미 열린 초안을 직접 편집할 수 있습니다. |
| 저장 결과를 확인하지 못함 | 다시 연결해 저장 여부를 확인하거나 **같은 요청 다시 시도**를 누릅니다. 같은 요청이 성공했다면 저장 버전을 중복으로 추가하지 않습니다. |
| 출력 요청의 결과를 확인하지 못함 | **같은 출력 요청 다시 확인**을 사용합니다. 새 출력을 반복해서 만들 필요가 없습니다. |
| 소스 컴파일 실패 | 표시된 오류를 현재 Codex에 전달해 수정하거나 **소스 다시 컴파일**을 누릅니다. 마지막 정상 미리보기가 있으면 유지합니다. |
| Chrome·Edge 설치 경로 오류 | 설치 경로를 확인합니다. 기본 경로 밖에 설치했다면 서비스 실행 전에 `CHROME_EXECUTABLE`에 실행 파일의 절대 경로를 지정합니다. |
| 터미널의 주소 사용 중 오류 | 같은 서비스가 이미 실행 중인지 확인합니다. 브라우저는 기본 4180 포트에 연결하므로 임의의 다른 포트로 실행하면 자동으로 따라가지 않습니다. |
| 다른 사이트 주소 또는 HTTPS 화면에서 연결 실패 | 로컬 실행 성공과 배포 화면 연결 성공은 별도입니다. 해당 주소의 허용 여부와 브라우저의 로컬 네트워크 접근 권한·정책을 확인합니다. HTTPS 연결 검증 결과는 [6단계 기록](remotion-studio-stage-6.md)을 따릅니다. |

기본 허용 화면은 `http://localhost:5173`, `http://127.0.0.1:5173`, `https://vyvyd.pages.dev`입니다. 다른 화면 주소를 사용해야 한다면 서비스의 `STUDIO_ALLOWED_ORIGIN`에 신뢰하는 정확한 origin 하나를 설정할 수 있습니다. 다른 주소의 허용은 그 화면에 로컬 프로젝트 접근을 제공하므로 의도한 vyvyd 주소만 사용하세요. 서비스는 `127.0.0.1`에만 실행됩니다. 브라우저 보안을 끄거나 서비스를 외부에 공개할 필요가 없습니다.

현재 [HTTPS 검토 화면](https://studio-proof.vyvyd.pages.dev/?studio=1)은 최신 기능을 담은 미리보기 배포입니다. 운영 화면과 주소가 다르므로, 이 검토 주소를 사용할 때는 기존 서비스를 종료하고 같은 터미널에서 다음처럼 실행합니다.

```powershell
$env:STUDIO_ALLOWED_ORIGIN='https://studio-proof.vyvyd.pages.dev'
npm run studio:server
```

일반 Chrome·Edge의 주소창에서 검토 주소를 열고, 해당 사이트에 로컬 네트워크 권한 요청이 나타나면 의도한 연결인지 확인합니다. 권한을 거부한 경우 사이트 설정에서 그 권한을 확인한 뒤 **다시 연결**합니다. 메뉴와 권한 이름은 브라우저 버전에 따라 다를 수 있습니다. 연결된 뒤 프로젝트·이미지·미리보기·재연결·다운로드를 함께 확인해야 합니다.

6단계의 Codex 내장 브라우저에서는 권한 요청 없이 두 번 연결에 실패했습니다. 이 실패를 일반 Chrome·Edge에서도 동일하게 재현한 것은 아닙니다. 지금 바로 작업할 수 있는 확인된 경로는 [로컬 포스터 메이커](http://127.0.0.1:5173/?studio=1)입니다. 구체적인 성공·실패 범위는 [6단계 기록](remotion-studio-stage-6.md)에 있습니다.

## 데이터와 AI 처리

영상·이미지 도구는 브라우저에서 처리하고 선택한 결과만 Discord로 전송합니다. 포스터 메이커는 이 컴퓨터의 로컬 서비스가 저장과 출력을 담당하며 별도의 AI API를 호출하지 않습니다.

로컬 데이터의 기본 위치는 `.local/studio/projects/`(소스·이미지·저장 이력), `.local/studio/previews/`(미리보기), `.local/studio/exports/`(출력 작업·결과)입니다. 모두 Git에서 제외합니다. 로컬 디스크에 남는 파일이므로 프로젝트 파일·다운로드 결과와 함께 필요에 맞게 보관하세요. 작업 중 이 폴더를 직접 수정하거나 삭제하면 연결·복구에 문제가 생길 수 있습니다.

**프로젝트 요청 문구 복사**는 프로젝트 ID·저장 버전·이름·선택 레이어 ID·작성한 요청과 미저장 여부를 클립보드에 넣습니다. 사용자가 현재 Codex 대화에 붙여넣고 작업을 요청하면 Codex가 도구로 읽은 소스·이미지·편집 값·미리보기 등이 그 대화의 AI 처리에 사용될 수 있습니다. 브라우저의 초안 전체를 자동으로 보내지는 않습니다. AI 작업에 필요한 직접 편집 값은 먼저 저장하세요.

로컬 서비스 연결은 저장·출력을 위한 연결이고 현재 Codex 연결은 사용자가 요청한 AI 작업을 위한 연결입니다. AI에 전달할 수 없는 자료는 해당 대화에 요청하거나 도구로 읽도록 지시하기 전에 확인하세요.
