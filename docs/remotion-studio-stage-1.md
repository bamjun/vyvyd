# 포스터 메이커: 1단계 프로젝트 기반

검증일: 2026-10-02  
상태: 프로젝트 생성·파일 보관·저장/복원 구현 완료. 사용자 검토 대기.

## 실행과 검토

두 터미널에서 각각 실행한다.

```powershell
npm run studio:server
```

```powershell
npm run dev
```

검토 주소: [포스터 메이커](http://127.0.0.1:5173/?studio=1)

서비스는 `127.0.0.1:4180`에서 실행한다. 기존 0단계 연결 시험의 `4179`와 별개다. 화면의 연결 표시는 프로젝트 저장 서비스의 상태이며, Codex MCP 연결은 2단계에서 구현한다.

## 제공하는 동작

- 빈 프로젝트 생성과 이름·가로/세로·FPS·길이·캔버스 배경 설정.
- 설정의 명시적 저장, 프로젝트 목록과 저장본 다시 열기.
- PNG·JPG·WebP·GIF 파일당 20 MiB 이하, 프로젝트당 100개까지 추가.
- 파일 추가 즉시 프로젝트에 복사. 같은 이름도 별도 ID로 보관.
- 이미지 추가 시 미저장 설정은 그대로 유지하며 자동 저장하지 않음.
- 새 페이지에서 마지막 프로젝트와 프레임 복원.
- 탭 이동 시 재생 정지와 프로젝트·현재 프레임·미저장 입력 유지.
- 저장 실패 시 입력 유지, 오래된 수정 번호의 요청은 충돌로 거부.

새 프로젝트는 디자인이 없는 흰 캔버스와 최소 Remotion 소스로 시작한다. 이미지 추가는 파일 목록과 파일 미리보기까지 제공한다. 자유 디자인을 현재 Codex에서 작성하는 연결은 2단계, 레이어 배치·문구 편집은 3단계 범위다.

## 저장 계약

```text
.local/studio/projects/<project-id>/
  project.json
  src/Root.tsx
  assets/<asset-id>.<extension>
```

문서 버전·ID·이름·수정 번호·시각·구성·소스 스냅샷·파일 목록·편집 값을 JSON에 보관하고 실제 소스와 이미지도 같은 폴더에 저장한다. `.local/studio/`는 Git 추적에서 제외한다.

공유 모델은 `packages/studio-runtime/src/project-model.mjs`다. 미리보기와 향후 렌더러는 `ProjectPreviewProps`의 `composition`과 `backgroundColor`를 동일하게 사용한다. 기본 소스의 `calculateMetadata`는 전달된 구성을 읽어, 설정 변경을 위해 자유 소스를 자동으로 다시 쓰지 않는다.

가로·세로는 64~8,192px 정수, FPS는 1~60 정수, 길이는 1~18,000프레임이다. 초 입력은 `round(초 × FPS)` 프레임으로 보관하고 실제 길이를 표시한다.

브라우저에는 마지막 프로젝트 ID와 프로젝트별 프레임만 보관한다. 프로젝트 문서와 이미지는 로컬 디스크가 기준이다. 미저장 설정은 현재 화면에서 유지되며 프로젝트 이동·새로고침 전에 이탈 확인을 제공한다. 미저장 초안의 영구 복원과 Undo/Redo는 4단계에서 다룬다.

## 서비스 경계와 설정

루프백에만 바인딩하며 프로젝트와 파일의 UUID·등록 경로로 접근한다. 소스는 `src/` 아래 20개·UTF-8 총 1 MiB 이내로 제한한다. Windows 경로 별칭·프로젝트 밖으로 향하는 연결된 파일과 폴더도 검사한다. 수정은 프로젝트별로 직렬화하고 문서는 임시 파일 기록·동기화 후 교체한다.

기본 허용 Origin은 `http://127.0.0.1:5173`, `http://localhost:5173`, `https://vyvyd.pages.dev`다. 다른 Origin과 `null`은 거부한다. 수정 API는 JSON 또는 지정 이미지 형식과 현재 수정 번호를 요구한다.

서비스 환경 변수는 `STUDIO_DATA_DIR`, `STUDIO_PORT`, `STUDIO_ALLOWED_ORIGIN`이다. 현재 화면은 `127.0.0.1:4180`에 연결하므로 포트를 바꾸면 `studioApi.ts`의 주소도 맞춰야 한다.
