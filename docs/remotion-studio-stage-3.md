# 포스터 메이커 3단계 — 레이어 직접 편집

작성일: 2026-10-03  
상태: 로컬 구현·검증 완료 · 사용자 검토 대기

## 구현한 동작

[포스터 메이커](http://127.0.0.1:5173/?studio=1)의 **레이어 편집** 모드에서 현재 프레임의 요소를 선택하고 조절합니다. **재생 보기**에서는 애니메이션을 확인합니다. 편집 모드는 재생을 멈추고 프레임 슬라이더로 원하는 시점을 선택합니다.

| 항목 | 동작 |
| --- | --- |
| 선택 | 레이어 목록 또는 캔버스의 표시 영역을 선택. 목록은 방향키·Home·End로 이동 |
| 이동 | 캔버스 드래그, 가로·세로 위치 입력. 캔버스에서 방향키 1px·Shift+방향키 10px 이동 |
| 크기·회전 | 너비·높이·회전·배율을 숫자로 입력. 리사이즈·회전 핸들은 포함하지 않음 |
| 문구·스타일 | 문구·글자 크기·색상·불투명도 입력 |
| 이미지 | 프로젝트에 보관한 이미지로 교체 |
| 숨김·잠금 | 지원하는 레이어에 표시. 잠기거나 상위 그룹이 잠기면 속성 변경·이동을 제한 |
| 순서 | 같은 DOM 부모의 측정된 레이어들이 `zIndex` 편집을 지원할 때 앞으로/뒤로 이동 |
| 초기화 | 선택한 레이어의 선언된 편집 값을 기본값으로 되돌림 |

모든 항목은 해당 레이어가 선언한 편집 속성만 표시합니다. 숫자가 비어 있거나 `-`처럼 입력 중인 문자열이면 미리보기에 잘못된 숫자를 보내지 않으며 마지막 유효한 값을 유지합니다. 외부 변경이나 기본값 복원으로 값이 바뀌면 입력 표시도 다시 맞춥니다.

## 저장과 Codex 후속 수정

위치·문구·이미지 등의 변경은 브라우저의 미저장 편집 값으로 즉시 미리보기에 반영합니다. **저장**을 눌러 프로젝트에 반영한 값은 현재 Codex가 MCP로 읽고 후속 소스 작업에 사용할 수 있습니다. 이미지 파일 추가는 기존 방식대로 즉시 보관합니다. 요청 문구 복사에는 선택한 레이어 ID와 미저장 변경 여부가 포함됩니다.

브라우저에 미저장 변경이 있는 동안 Codex가 저장본을 바꾸면 입력을 유지하고 충돌 안내를 표시합니다. **최신 저장본 다시 읽기** 또는 **내 입력 유지하고 최신 버전 사용**을 선택합니다. 입력 유지 경로는 사용자가 바꾼 속성·삭제한 편집 값만 최신 저장본에 적용하며, 사용자가 건드리지 않은 Codex의 변경은 유지합니다.

새 소스에서 레이어가 삭제됐거나 편집 속성이 지원되지 않거나 교체한 이미지가 없어졌다면 적용하지 못한 항목을 안내합니다. 조용히 덮어쓰거나 사라진 요소에 편집 값을 계속 적용하지 않습니다. 저장 실패 때 입력은 유지하며, 저장 버전과 미리보기 버전이 일치하기 전에는 직접 편집을 잠시 제한합니다.

## 코드와 레이어의 연결 규칙

Codex는 `src/layers.json`에 고유한 ID·이름·종류·지원 속성·기본값을 등록하고, 화면의 대응하는 요소에 `data-layer-id="같은 ID"`를 붙입니다. 한 ID는 하나의 실제 DOM 요소를 식별해야 합니다. 소스는 기본값과 `props.layers[id]`를 합쳐 위치·문구·스타일 등을 표시해야 합니다. 레이어를 등록하기만 하고 편집 값을 사용하지 않는 코드가 자동으로 수정되지는 않습니다.

캔버스 선택 영역은 iframe 안의 실제 DOM 위치와 크기로 계산합니다. 캔버스 배율과 지원하는 부모의 2D 회전·크기 변환을 반영해 이동량을 레이어의 기준 좌표로 바꿉니다. 표시 위치는 현재 애니메이션 프레임의 위치이며 숫자 입력의 위치는 코드가 정의한 기준 위치입니다. 애니메이션은 이 기준 위치와 편집 값을 합성하도록 작성합니다.

현재 편집 입력과 동기화 상태가 일치하는 측정 결과만 선택 영역에 반영하고 이전 결과는 제거합니다. 브라우저가 숨겨진 상태에서도 선택 영역이 새 크기·회전·이미지에 맞게 갱신되도록 보완했습니다. 최종 확인은 미리보기 프로토콜 버전 4에서 수행했습니다.

순서 변경은 등록된 그룹 이름만으로 판단하지 않고 실제 DOM 부모가 같은지 확인합니다. 다른 부모나 중첩 그룹을 넘겨 이동하는 기능은 포함하지 않습니다. 잠긴 레이어의 순서 값을 바꿔야 하는 작업도 제한합니다.

임의 JSX의 모든 요소를 자동으로 편집 대상으로 만들지는 않습니다. SVG 내부 요소는 HTML 래퍼에 편집 ID를 붙이는 방식으로 작성합니다. 3D·원근 변환 등 이동 기준을 안전하게 계산할 수 없는 요소는 캔버스 드래그를 지원하지 않습니다. 지원 속성의 숫자 입력과 소스 수정은 별도 경로입니다.

## 검증 기록

검토 프로젝트는 **단계 2 Codex 연결 포스터**, ID `9059b75c-b3d2-4307-b64a-16060305e40d`입니다. 실제 브라우저에서 직접 선택·이동·속성 수정·이미지 교체·저장을 실행했고, 현재 Codex 대화의 실제 MCP로 저장된 편집 값을 읽고 소스를 후속 수정했습니다.

600×800 프로젝트를 390×520 CSS px 캔버스에서 확인했습니다. 제목을 20 CSS px씩 드래그하자 기준 위치가 `(50, 148)`에서 `(80.77, 178.77)`로 바뀌었습니다. 캔버스 배율을 반영한 이동량이며 Shift+오른쪽 방향키로 가로 위치가 `90.77`이 됐습니다. 제목의 회전 2°·너비 440·글자 크기 58·색상 `#1c2240`과 문구 변경도 확인했습니다. 설명 문구와 세로 위치 352를 수정했습니다.

제목 숨김은 실제 DOM에서 요소가 사라지는 것으로, 잠금은 속성 입력 비활성화로 확인했습니다. 가로 위치를 빈 문자열로 입력해도 유효한 값 48이 유지됐고, 기본값 복원으로 입력과 미리보기가 기본값으로 돌아왔습니다. 이 입력·복원 확인은 이동 검증과 별도로 수행했습니다.

브라우저 파일 선택기로 2단계에서 만든 `direct-mcp.png`를 추가하고 이미지 레이어를 교체했습니다. 프로젝트에 보관된 파일 ID는 `941bbc1e-e02e-44b6-8b2d-ad6608976e73`이며, 너비 72·높이 96·회전 -5°를 적용했습니다.

버전 **9**로 저장한 뒤 현재 Codex가 실제 MCP로 같은 버전을 읽었습니다. 궤도 애니메이션 계수를 `0.95`에서 `0.55`로 바꾼 소스를 적용해 버전 **10**이 됐고, 적용 전후 레이어 편집 값의 JSON이 정확히 같은 것을 확인했습니다. 제목을 앞으로 두 번 옮긴 뒤 버전 **11**로 저장했고, 유효한 순서 값은 제목 4·설명 1·이미지 3이었습니다. **저장본 다시 열기**에서도 버전 11과 편집 값을 확인했습니다.

좌표 동기화 보완 뒤 실제 브라우저에서 이미지 회전을 -5°→10°로 바꾸고, 이미지 교체와 너비 100·높이 80을 연속 적용했습니다. 한 번의 UI 실행 안에서 미리보기와 선택 영역이 변경된 모양에 맞는 것을 확인했습니다. 확인 후 저장된 이미지·너비 72·높이 96·회전 -5°를 다시 적용해 미저장 변경이 없는 상태로 돌렸습니다. 프로토콜 4의 제목 선택 영역에서도 왼쪽 방향키로 가로 위치 89.77, 오른쪽 방향키로 90.77을 확인하고 저장본과 같은 값으로 복원했습니다.

로컬 서비스를 실제 종료·재시작한 뒤 현재 Codex의 MCP가 버전 11의 편집 값과 파일 목록을 읽어 재시작 전 JSON과 정확히 같은 것을 확인했습니다. 미리보기 프로토콜 4로 다시 컴파일한 뒤 브라우저를 새로고침했고, 저장 버전과 소스 표시 버전 11·MCP 연결·이미지 2개·47프레임이 복원됐습니다.

## 이후 단계와 실행 범위

Undo/Redo·수정 이력 UI와 연결 복구 완성은 4단계, PNG·GIF·MP4 출력 UI와 기존 도구로 전달은 5단계입니다. 이번 단계는 기존 로컬 서비스와 로컬 vyvyd에서 구현했습니다. 배포된 HTTPS 화면과 로컬 서비스의 연결은 아직 성공 확인 전이며 6단계에서 별도로 검증합니다.

기존 `ad-mage`의 템플릿·디자인·파일을 가져오는 작업은 포함하지 않습니다. AI 제작과 수정 요청은 현재 Codex 대화에서 처리합니다.
